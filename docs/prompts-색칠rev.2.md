## 이 세션에서 실제로 반영된 변경

- **음성 멘트 안 나오던 문제(모바일)** 3단계로 해결: ① `speechSynthesis.speak()` setTimeout 지연 제거(동기 호출), ② 크롬 GC 버그 방지(utterance 참조 유지), ③ 기기에 TTS 음성 자체가 없으면 음성 대신 축하 차임(Web Audio 합성) 자동 대체
- 폰 화면 꺼도 배경음악이 계속 나오던 문제 — `visibilitychange`에서 pause/resume
- **레벨 갤러리 시간초과 후 체크표시 잔류 버그** — `renderLevelGallery()`가 scores를 캡처한 뒤에 리셋을 감지하는 순서 문제였음, 헤드리스로 재현/검증 후 수정
- 레벨클리어 문구 "Level N Clear!" → "Clear!" 단순화
- 맵 화면 "N more levels to go!" 문구 삭제
- 시작 화면 아무 곳이나 눌러도 나오던 배경음악 → Start 눌러야 나오게
- 클리어된 레벨 박스 배경 라이트/다크 모드 모두 확실한 분홍(다크모드에서 갈색으로 보이던 문제 재수정)
- 보스 클리어 화면의 Print My Art / Print Blank Page 버튼 + 인쇄 기능 전체 제거
- Next/Back 버튼 음성 지연(콜드스타트) — 맵 진입 시점에 미리 무음 예열(warmUpSpeech)
- 그림 전환 시 이전 그림이 잠깐 남아 보이던 잔상 버그 — 화면 전환 즉시 캔버스 비움
- 레벨 1~10 박스 키캡(입체감) 스타일 + 클리어 시 분홍색
- **앱스토어 출시 대비 최초실행 온보딩** 추가: 보호자 확인 게이트(랜덤 덧셈 문제) → 이용안내 동의(광고없음/오프라인/개인정보 안내) → `privacy.html` 개인정보처리방침 신규 작성(문의: mrkyp@hanmail.net)
- **로컬 랭킹 → 전 세계 공용 랭킹**으로 전환: 닉네임(자유입력)+국기 이모지(고정 21개 목록)만 공개, 실명/자유입력 국가는 요구하지 않음. 백엔드는 Firebase Realtime Database(REST, SDK 없이 fetch만 사용) — **아직 실제 프로젝트 URL 연동 전, 사용자가 Firebase 콘솔에서 프로젝트/DB 만들어서 URL 전달 예정**
- 닉네임/국기는 한 번 등록하면 이후 수정 불가(잠금 UI + 경고문구)
- Twemoji(CC-BY 4.0) 출처 표시를 `privacy.html`에 Credits로 추가
- 로딩 화면(요정 마스코트 + 스피너) 추가
- 앱 아이콘을 색깔 점 4개 → 요정 캐릭터(+반짝이 4개, maskable 안전영역 준수)로 교체, `scripts/make-icons.js`를 Puppeteer 렌더 방식으로 재작성

## 결정된 사항(코드 변경은 아니지만 방향이 확정된 것)

- **가격**: $1 일회성 결제, 평생 이용(구독 아님, 앱 내 결제 로직 불필요 — 스토어가 다운로드 시점에 처리)
- **난이도**: Hard/Very Hard가 성인도 어렵다는 걸 확인했지만, 하향 조정 대신 **일반 패밀리 앱으로 등록**(유아 전용/Kids Category 아님)해서 "부모와 같이 도전"으로 포지셔닝하기로 결정 — 난이도 자체는 유지
- **출시 플랫폼 순서**: 안드로이드(Google Play) 먼저, iOS는 나중
- **실제 스토어 출시까지 남은 일**(사용자가 직접 해야 하는 것): Google Play Console 계정 가입/본인인증($25, 1회), Firebase 프로젝트 생성 후 DB URL 전달, (나중에) 정산 계좌/세금 정보

## 보류/다음 세션 예정

- Firebase 프로젝트 URL 연동 + 정식 보안 규칙 적용(현재 코드는 URL 미설정 상태로 "설정 전" 안내만 뜨고 비활성화)
- 앱 내 화면 디자인 추가로 다듬기(사용자가 아이디어 구상 중, 다음 세션에 이어서)
